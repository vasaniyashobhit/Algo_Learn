Vlad and the Nice Paths (hard version)

dp combinatorics math

Hints

AI hints from Gemini. They can be wrong, so check each step yourself.

  1. Let dp[i] be the longest nice path that ends exactly at tile i, together with how many paths reach that length.

  2. To close a block at i, walk left from i counting tiles of colour ci. Once you have passed k − 1 of them, every earlier start works, and the middle tiles can be chosen in a binomial number of ways.

  3. Only extend from states that already have the maximum length. Precompute binomials up to 5000 modulo 109+7, and the whole thing is O(n²).

Full solution

Try the hints first. The solution stays here when you're ready.

Process tiles left to right. For each i, scan j from i down to 1 and count tiles of colour ci; when the count reaches k, block start j is valid and contributes ways[j−1] · C(cnt−2, k−2) to the length len[j−1] + 1. Keep only the best length per i.

for i in 1..n:
  cnt = 0
  for j in i down to 1:
    if c[j] == c[i]: cnt += 1
    if cnt >= k and len[j-1] + 1 >= len[i]: update(i, j, cnt)
