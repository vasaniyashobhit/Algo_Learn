  2. hint 2

    To close a block at i, walk left counting tiles of colour ci. After k − 1 of them, any earlier start works; the middle tiles are a binomial choice.

Full solution

Give the hints a real try first. It'll be here.

For each i, scan j from i down while counting colour ci. When the count reaches k, start j adds ways[j−1] · C(cnt−2, k−2) at length len[j−1] + 1. Keep the best length per i.

for i in 1..n:
  cnt = 0
  for j in i down to 1:
    if c[j] == c[i]: cnt += 1
    if cnt >= k: relax(i, j, cnt)
