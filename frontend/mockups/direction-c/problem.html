Vlad and the Nice Paths (hard version)

combinatorics dp math

I'm stuck on this

There are $n$ tiles in a row, numbered $1$ to $n$; tile $i$ has colour $c_i$. Vlad starts on any tile and may only jump to tiles to the right.

A path of length $p$ visits tiles $j_1 < j_2 < \dots < j_p$. It is nice if $p$ is divisible by $k$ and each block of $k$ consecutive visited tiles has one colour: $$c_{j_1} = \dots = c_{j_k},\quad c_{j_{k+1}} = \dots = c_{j_{2k}},\ \dots$$

Count the nice paths of maximum length, modulo $10^9 + 7$.

Input

$t$ tests ($1 \le t \le 10^4$). Each has $n$ and $k$ ($1 \le k \le n \le 5000$) and colours $c_1, \dots, c_n$. The sum of $n^2$ over all tests is at most $2.5 \cdot 10^7$.

Output

For each test, the number of nice paths of maximum length modulo $10^9 + 7$.
